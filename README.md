## 怎么编译运行

方式一，用脚本（Windows PowerShell）：

```powershell
.\run.ps1 第5章\swap_task.c
```

`run.ps1` 里 gcc 的路径是写死的，换电脑要改第 6 行的 `$gcc`。

方式二，直接用 gcc：

```bash
gcc -std=c99 -Wall -Wextra -g 第5章/swap_task.c -o swap_task.exe
./swap_task.exe
```

中文输出乱码的话，加编码参数：

```bash
gcc -finput-charset=UTF-8 -fexec-charset=UTF-8 xx.c -o xx.exe
```
